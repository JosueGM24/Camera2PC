Toque

Tu teléfono o tablet como teclado y trackpad de tu PC, por WiFi y desde el navegador.

Toque se ejecuta en tu propia computadora. Necesita mover el cursor y escribir en tu escritorio, así que no hay una versión alojada: descarga el proyecto y córrelo en la PC que quieras controlar.

Instalar

git clone https://github.com/<usuario>/toque
cd toque
npm install
npm start

Usar

  1. Al iniciar se abre una página con un código QR.
  2. Escanéalo con la cámara del teléfono, en la misma red WiFi.
  3. Arriba tienes el trackpad; abajo, el teclado.
