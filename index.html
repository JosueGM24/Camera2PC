Conectar por cable USB

El truco no es el USB en si, sino conseguir un enlace IP por el cable. El anclaje por USB hace exactamente eso y la conexion elige esa ruta sola: menos latencia, sin saturar el Wi-Fi, y el telefono se carga.

  1. Conecta el cable.
  2. Android: Ajustes → Conexiones → Zona Wi-Fi y anclaje → Anclaje por USB.
    iPhone o iPad: Ajustes → Compartir Internet → activado.
  3. Abre las paginas como siempre.
  4. Mira el camino de la senal: si dice cable USB, va por el cable.

Sin internet tambien funciona, con un servidor local y adb: npm run local y npm run usb.

Usarla como camara web en Teams o Zoom
  1. Abre Recibir en la PC y copia la direccion para OBS.
  2. En OBS Studio: Fuentes → + → Navegador. Pega la direccion, ancho 1920, alto 1080.
  3. Clic derecho en la fuente → Cambiar a pantalla completa.
  4. Pulsa Iniciar camara virtual.
  5. En Teams o Zoom, elige la camara OBS Virtual Camera.

El navegador no puede registrar una camara del sistema por si solo. OBS aporta ese driver, ya firmado, asi no instalas nada hecho a mano.

Segundo monitor: hasta donde llega

Compartir manda un monitor, una ventana o una pestana a la tablet. Es un monitor espejo: Windows no ve la tablet como pantalla, asi que no puedes arrastrar ventanas ahi ni controlar la PC tocandola.

Para un escritorio extendido de verdad, instala un driver de pantalla virtual (Virtual Display Driver, gratuito). Windows te da un monitor extra autentico; en Compartir eliges ese monitor y la tablet lo muestra. Mismo patron que OBS con la camara.
