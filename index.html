Conectar por cable USB

El truco no es el USB en si, sino conseguir un enlace IP por el cable. El anclaje por USB hace exactamente eso y la conexion elige esa ruta sola: menos latencia, sin saturar el Wi-Fi, y el telefono se carga.

  1. Conecta el cable.
  2. Android: Ajustes → Conexiones → Zona Wi-Fi y anclaje → Anclaje por USB.
    iPhone o iPad: Ajustes → Compartir Internet → activado.
  3. Abre las paginas como siempre.
  4. Mira el camino de la senal: si dice cable USB, va por el cable.

Sin internet tambien funciona, con un servidor local y adb: npm run local y npm run usb.

Segundo monitor: como queda extendido

Una pagina web no puede registrar una pantalla en Windows, igual que no puede registrar una camara. La pieza que falta es un driver de pantalla virtual: se instala una vez, Windows te da un monitor extra autentico al que arrastras ventanas, y Compartir lo manda a la tablet.

No instalas nada en la tablet, solo el navegador, y viaja por el mismo cable USB. Los pasos estan dentro de Compartir.

Sin el driver sigue funcionando como espejo, que sirve para mandar una ventana suelta a la tablet sin tocar tu escritorio.
