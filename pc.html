Codigo de sala

------

El codigo se guarda en este navegador, asi la URL de OBS no cambia entre reinicios. Usa Codigo nuevo solo si quieres invalidar el anterior.

URL para OBS (camara virtual)

  1. OBS → Fuentes → + → Navegador, pega esta URL.
  2. Ancho 1920, alto 1080, FPS 30.
  3. Marca Controlar audio mediante OBS si quieres el micro del telefono.
  4. Menu Herramientas (o el boton) → Iniciar camara virtual.
  5. En Teams o Zoom elige OBS Virtual Camera.
